Подтверждение перечисляет пути и размеры; затем снимается доступ, закрывается окно tmux с сессией, удаляются `USERS_DIR/<id>` и транскрипты Claude Code, история лички, очередь, память, напоминания и настройки чата. Вариант «и исключить из группы» — ban+unban, без вечного бана.

- Новый пользователь в `allowFrom` — откуда бы он ни появился (`/invite`, access-skill, правка файла) — получает папку, запущенную сессию, а владелец — шаги и приглашение для пересылки. При первом запуске новыми считаются те, у кого нет папки в `USERS_DIR`.
- Отчёт с долей «<1%» падал на разборе HTML.
- Инструкции канала: команды, пути и id — в `коде`, чтобы копировались нажатием.
- Сессия пользователя называется `claude-<telegram id>` вместо `claude-<username>`: username может отсутствовать или смениться.
- **👥 Приглашение из бота:** `/invite` или кнопка в `/sessions` (только владелец, в личке) → выбор контакта стандартной кнопкой Telegram → подтверждение с предупреждением о полном доступе → добавление в `allowFrom`, папка и запуск сессии `claude-<telegram id>`, одноразовая ссылка в группу, шаги для владельца (с «👁 Экран» для подтверждения запуска) и готовое приглашение для пересылки.
- **📊 Отчёты за сутки, неделю и месяц** (`/reports`, каждый включается отдельно, по умолчанию выключены): когда период закончился, владельцу приходит график расхода (по часам / дням / неделям; SVG → PNG локально через resvg) и статистика — итог и изменение к прошлому периоду, ответы модели, активные часы/дни и пик, модели, сессии с коммитами, доля кэша, лимиты. Кнопки «📨» присылают отчёт за прошлый период сразу. Кэш транскриптов теперь держит 64 дня.
- **⏰ Напоминания и отложенные задачи:** `/remind <когда> <текст>` (30m, 1h30m, «через 2 часа», 18:30, «завтра 9:00», «каждый день 9:00») и `/reminders` со списком и 🗑. В срок текст появляется в чате и приходит сессии этого чата (`event="reminder"`), а если она не запущена — запускает её. Инструмент `remind` даёт сессии самой поставить себе задачу на потом.
- **Разрешения:** кнопка «♾ Всегда <инструмент> в этой сессии»: дальнейшие запросы этого инструмента одобряются без вопроса, пока сессия не переподключится; в карточке строка «♾ без вопросов» и кнопка сброса. `/permissions` и кнопка в `/sessions` — все ждущие запросы по всем сессиям с ✅/❌.
- **`/topics` как меню:** список рабочих топиков с состоянием (сессия, 💤 без сессии, очередь) и кнопкой на каждый, отдельно архив. Экран топика: 💬 Открыть, 📋 карточка сессии, 🚀 Запустить сессию, 🗄 В архив / ↩️ Восстановить, 🗑 Удалить (подтверждение на месте). Строка 🔧 и полные карточки остались только в `/sessions`.
- **💸 Стоимость и итоги дня:** в карточке сессии расход за сегодня в ценах API. В `DIGEST_AT` (21:00, `off` — выкл.) владельцу приходят «🌙 Итоги дня»: расход по сессиям, коммиты за день по проектам (без merge), лимиты. По запросу — `/digest`.
- **🌿 Git в карточке сессии:** `git status -sb`, последние 5 коммитов, PR ветки (через `gh`, если он установлен и авторизован) и «📄 diff файлом» (`git diff HEAD`, секреты маскируются).
- **Управление сессией:** в карточке `/sessions` кнопки 🧹 `/compact`, 🆕 `/clear` (с подтверждением) и 🧠 Модель (opus/sonnet/haiku/fable → `/model <id>`). Команды набираются в окне tmux и только между ходами. Когда контекст переходит `CONTEXT_WARN_PCT` (80%), в чат сессии приходит предложение сжать с кнопкой `/compact`, один раз за заполнение.
- **Уведомления о лимитах:** раз в `LIMIT_CHECK_MIN` минут (10) демон проверяет лимиты подписки и пишет владельцу, когда лимит перешёл порог `LIMIT_ALERTS` (`80,95`; `off` — выключить), и «✅ восстановился» после сброса окна. В закреплённой сводке General строка «📊 5 часов 42% · Неделя 31%».
- **👁 Экран и клавиши:** в карточке сессии и в сообщениях о запуске кнопка «👁 Экран и клавиши» показывает окно tmux и даёт нажать 1/2/3, Enter, Esc, ↑/↓, Tab. Экран подтверждения каналов принимается прямо из Telegram. `SCREEN_REDRAW_MS` — пауза перед повторным снимком.

## 1.1.0 — 2026-10-28

- **Типы сессий:** 👤 сессия пользователя в `USERS_DIR/<user_id>` (по умолчанию `~/user/<id>`) — личка этого пользователя и его сообщения в General, ответ туда же; 📂 сессия проекта — свой топик. Главная (`MAIN_DIR`) нужна только при `USER_SESSIONS=off` (поведение 1.0) или для `TOPIC_NO_SESSION=main`.
- **Запуск по требованию:** первое сообщение пользователя запускает его сессию в tmux (с `--continue`), сообщение топика без сессии — сессию проекта (`TOPIC_NO_SESSION=launch`). Ошибка запуска → команда для ручного запуска, топик закрыт до подключения. Владелец получает уведомление, когда нужно подтвердить запуск для другого пользователя.
- **Сторож сессий в демоне:** остановившаяся сама сессия через `WATCHDOG_GRACE_SEC` сообщает об этом в свой чат с командами и кнопкой «🚀 Запустить»; топик проекта закрывается до переподключения.
- Авто-закрытие простаивающих сессий: `USER_IDLE_MIN`, `PROJECT_IDLE_MIN` (по умолчанию 0 — не закрывать).
- Запросы разрешений сессии пользователя идут только ему. Сообщения в очереди помечены, откуда пришли (General/топик).
- **`/usage`** в личке (владелец): план подписки, проценты лимитов 5 часов и недели со временем сброса (незадокументированный эндпоинт, `USAGE_LIMITS=off` отключает), расход токенов и стоимость в ценах API за 5 часов, сутки и 7 дней, по моделям и сессиям.
- **Подробность уведомлений видна:** 🔕0 / 🔔1 / 📢2 в шапке «⏳ Работаю…», строка 📣 в карточках сессий вместе с режимом «✅ готово», `/verbose` и `/notify_done` без аргумента показывают текущие настройки.
- **Имена сессий:** запуск из бота и команды в подсказках (ошибка запуска, сторож) передают `-n claude-<username>` для сессии пользователя и `-n claude-topic-<топик>` для проекта; так же называется окно tmux. Главная сессия — по имени папки, без `-n`.
- **`/sessions` как меню BotFather:** одно сообщение, список сессий с кнопкой на каждую → карточка сессии с действиями (стоп, сделать главной, в архив с подтверждением на месте, открыть топик) и переключателями подробности и «✅ готово» для её чата → «« К списку».
- README: раздел «Типы сессий» с ручными шагами и недостатками; ТЗ §5.3c.

## 1.0.1 — 2026-10-28

- **Главная сессия:** личка отделена от топиков. Лички всех пользователей и текст в General получает сессия в `MAIN_DIR` (по умолчанию домашняя папка); у неё нет своего топика. `/main <id>` переназначает главную, `/main reset` возвращает `MAIN_DIR`, `/use` остался синонимом.

- Неизвестные команды в General больше не отвечают «Это пульт» и не уходят в сессию.

## 0.2.0 — 2026-10-28

- **Проекты из топиков:** топик, созданный владельцем, → папка в `PROJECTS_DIR`, привязка топика и новая сессия Claude в окне tmux; `/new_session <имя|путь>`; `TOPIC_PROJECTS=auto|ask|off`.
- **Архив сессий и топиков:** кнопка «🗄 Архив» в `/sessions` и `/topics` (с подтверждением) закрывает сессию (`Esc` + `/exit` в tmux) и закрывает топик.
