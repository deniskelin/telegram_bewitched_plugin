# Changelog

## Unreleased

- **Типы сессий:** 👤 сессия пользователя в `USERS_DIR/<user_id>` (по умолчанию `~/user/<id>`) — личка этого пользователя и его сообщения в General, ответ туда же; 📂 сессия проекта — свой топик. Главная (`MAIN_DIR`) нужна только при `USER_SESSIONS=off` (поведение 1.0) или для `TOPIC_NO_SESSION=main`.
- **Запуск по требованию:** первое сообщение пользователя запускает его сессию в tmux (с `--continue`), сообщение топика без сессии — сессию проекта (`TOPIC_NO_SESSION=launch`). Ошибка запуска → команда для ручного запуска, топик закрыт до подключения. Владелец получает уведомление, когда нужно подтвердить запуск для другого пользователя.
- **Сторож сессий в демоне:** остановившаяся сама сессия через `WATCHDOG_GRACE_SEC` сообщает об этом в свой чат с командами и кнопкой «🚀 Запустить»; топик проекта закрывается до переподключения.
- Авто-закрытие простаивающих сессий: `USER_IDLE_MIN`, `PROJECT_IDLE_MIN` (по умолчанию 0 — не закрывать).
- Запросы разрешений сессии пользователя идут только ему. Сообщения в очереди помечены, откуда пришли (General/топик).
- **`/usage`** в личке (владелец): план подписки, проценты лимитов 5 часов и недели со временем сброса (незадокументированный эндпоинт, `USAGE_LIMITS=off` отключает), расход токенов и стоимость в ценах API за 5 часов, сутки и 7 дней, по моделям и сессиям.
- **Подробность уведомлений видна:** 🔕0 / 🔔1 / 📢2 в шапке «⏳ Работаю…», строка 📣 в карточках сессий вместе с режимом «✅ готово», `/verbose` и `/notify_done` без аргумента показывают текущие настройки.
- **Имена сессий:** запуск из бота и команды в подсказках (ошибка запуска, сторож) передают `-n claude-<username>` для сессии пользователя и `-n claude-topic-<топик>` для проекта; так же называется окно tmux. Главная сессия — по имени папки, без `-n`.
- README: раздел «Типы сессий» с ручными шагами и недостатками; ТЗ §5.3c.

## 1.0.3 — 2026-10-28

- Карточки сессий переделаны: заголовок (имя, статус с длительностью хода, ветка и топик), главное в цитате (`tmux attach`, режим разрешений · стоп · RC одной строкой, модель и контекст, текущее действие), детали в свёрнутой цитате. Кнопки `/sessions`: ряд на сессию, первая — её имя.
- Remote Control, модель и контекст сразу после перезапуска демона: транскрипт находится по `--resume <id>` или `--continue` сессии; пока он неизвестен, RC показывается как «?», а не «выкл».
- `/sessions` и `/topics`: сессии без канала (запущенные без `--dangerously-load-development-channels` или `claude -p`) показываются блоком «👻 Без канала» с папкой, окном tmux и командой перезапуска с теми же аргументами и флагом каналов.

## 1.0.2 — 2026-10-28

- `/sessions` и `/topics`: карточка на каждую сессию — тип (👑 главная / проектная), статус, `#id` и pid, папка, ветка, топик, сессия, окно и панель tmux с командой `tmux attach -t <сессия>:<окно>`, доступность «⏹ Стоп», 🛡 режим разрешений, 🧠 модель и размер контекста (`CONTEXT_WINDOW`), ⏳ текущий ход и последнее действие, 🧾 `claude --resume <id>`, 🏷 имя из `/rename`, 📱 Remote Control со ссылкой на сессию в claude.ai (из транскрипта, иначе по флагу запуска или `remoteControlAtStartup`), время с запуска и последней активности. В `/topics` также топики без сессии с числом сообщений в очереди и архив. Главная сессия первой, в пульте она помечена 👑.

## 1.0.1 — 2026-10-28

- **Главная сессия:** личка отделена от топиков. Лички всех пользователей и текст в General получает сессия в `MAIN_DIR` (по умолчанию домашняя папка); у неё нет своего топика. `/main <id>` переназначает главную, `/main reset` возвращает `MAIN_DIR`, `/use` остался синонимом.
- Топик проекта без запущенной сессии обслуживает главная и отвечает в этот топик. Сессия проекта при запуске получает такие сообщения как уже обработанные, для контекста.
- Без главной сессии сообщения из лички и General ждут её в отдельной очереди.
- Неизвестные команды в General больше не отвечают «Это пульт» и не уходят в сессию.

## 1.0.0 — 2026-10-28

Первый стабильный релиз.

- Панель tmux определяется по процессу `claude`, даже если MCP-серверы не унаследовали `TMUX_PANE`.
- README: таблица сравнения с официальным плагином.
- Версия MCP-сервера теперь совпадает с версией плагина.

## 0.2.0 — 2026-10-28

- **Проекты из топиков:** топик, созданный владельцем, → папка в `PROJECTS_DIR`, привязка топика и новая сессия Claude в окне tmux; `/new_session <имя|путь>`; `TOPIC_PROJECTS=auto|ask|off`.
- **Архив сессий и топиков:** кнопка «🗄 Архив» в `/sessions` и `/topics` (с подтверждением) закрывает сессию (`Esc` + `/exit` в tmux) и закрывает топик. Закрытие/переоткрытие топика в Telegram, ↩️ в `/topics` и новая сессия в проекте синхронизируют состояние в обе стороны; переоткрытие запускает сессию. Сообщения в архивный топик сохраняются, с кнопкой «▶️ Восстановить».
- **Права:** все пользователи из allowlist бота равны владельцу. Группа топиков подключается с `allowPaired: true` — писать в топики и управлять сессиями могут все сопряжённые. Для уже подключённой группы — `bewitched group allow-paired` в терминале.
- Предупреждение владельцу в личку, когда опрос заблокирован другим процессом (официальный плагин, в том числе `telegram@synced`).

## 0.1.0 — 2026-10-28

Этапы 0–5 из [docs/TZ.md](docs/TZ.md).

- **Основа:** плагин `telegram-bewitched` с marketplace `bewitched`, отдельный каталог состояния `~/.claude/channels/telegram-bewitched` с миграцией из официального, модульная структура, обёртка Bot API 10.x (`sendRichMessageDraft`, `sendRichMessage`, `can_stop`).
- **Демон:** один процесс опроса на все сессии, unix-сокет, тонкий MCP-клиент на сессию, автозапуск, пассивные сессии (`claude -p`) не перехватывают входящие, ожидание при работающем официальном плагине, общий обработчик 429.
- **История:** SQLite + FTS5, `reply_to_*`, `quote_text`, `forward_*`, пачки пересылок, `get_history`, `search_messages`, `get_message`, `save_memory`/`read_memory`, сводка при подключении сессии.
- **Топики:** подключение форум-супергруппы из лички (`/connect_group`), топик на проект, пульт в General с закреплённой сводкой, команды управления, отложенная доставка, `notify`, авто-уведомление о завершении долгого хода, HTTP `/notify` и CLI.
- **Стриминг:** хуки `PreToolUse`/`MessageDisplay`/`Stop` → черновик в личке или обновляемое сообщение в топике, `/verbose`, кнопка «⏹ Стоп» с прерыванием через tmux.
- **Кнопки:** `ask_user`, `reply(buttons)`, множественный выбор, таймаут, ответ текстом на вопрос.
