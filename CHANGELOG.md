# Changelog

## 0.2.0 — 2026-10-28

- **Проекты из топиков:** топик, созданный владельцем, → папка в `PROJECTS_DIR`, привязка топика и новая сессия Claude в окне tmux; `/new_session <имя|путь>`; `TOPIC_PROJECTS=auto|ask|off`.
- **Архив сессий и топиков:** кнопка «🗄 Архив» в `/sessions` и `/topics` (с подтверждением) закрывает сессию (`Esc` + `/exit` в tmux) и закрывает топик. Закрытие/переоткрытие топика в Telegram, ↩️ в `/topics` и новая сессия в проекте синхронизируют состояние в обе стороны; переоткрытие запускает сессию. Сообщения в архивный топик сохраняются, с кнопкой «▶️ Восстановить».
- Предупреждение владельцу в личку, когда опрос заблокирован другим процессом (официальный плагин, в том числе `telegram@synced`).

## 0.1.0 — 2026-10-28

Этапы 0–5 из [docs/TZ.md](docs/TZ.md).

- **Основа:** плагин `telegram-bewitched` с marketplace `bewitched`, отдельный каталог состояния `~/.claude/channels/telegram-bewitched` с миграцией из официального, модульная структура, обёртка Bot API 10.x (`sendRichMessageDraft`, `sendRichMessage`, `can_stop`).
- **Демон:** один процесс опроса на все сессии, unix-сокет, тонкий MCP-клиент на сессию, автозапуск, пассивные сессии (`claude -p`) не перехватывают входящие, ожидание при работающем официальном плагине, общий обработчик 429.
- **История:** SQLite + FTS5, `reply_to_*`, `quote_text`, `forward_*`, пачки пересылок, `get_history`, `search_messages`, `get_message`, `save_memory`/`read_memory`, сводка при подключении сессии.
- **Топики:** подключение форум-супергруппы из лички (`/connect_group`), топик на проект, пульт в General с закреплённой сводкой, команды управления, отложенная доставка, `notify`, авто-уведомление о завершении долгого хода, HTTP `/notify` и CLI.
- **Стриминг:** хуки `PreToolUse`/`MessageDisplay`/`Stop` → черновик в личке или обновляемое сообщение в топике, `/verbose`, кнопка «⏹ Стоп» с прерыванием через tmux.
- **Кнопки:** `ask_user`, `reply(buttons)`, множественный выбор, таймаут, ответ текстом на вопрос.
